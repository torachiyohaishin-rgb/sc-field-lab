SC Field Lab｜情報処理安全確保支援士 科目B 弱点対策

【アプリの使い方】
・「ホーム」から今日の5問を開始。4択は自動正誤判定、記述は模範答案と自己評価。
・弱点ライブラリで仕組み、攻撃者、防御者、答案の要点を確認。
・新しい弱点、演習問題、過去問結果を追加できます。
・「設定・保存」でJSONバックアップを定期的に保存してください。

【スマホのホーム画面に追加する（PWA）】
このZIPを展開してフォルダごとHTTPS対応の静的Webホスティング（Vercel、GitHub Pagesなど）に配置してください。index.htmlを公開URLで開き、iPhoneのSafariの共有メニューから「ホーム画面に追加」を選択できます。
※Webへの公開・ドメイン設定は、このZIPをダウンロードしただけでは行われません。
※データは利用中のブラウザ内に保存され、別端末へは自動同期されません。
※「SC_Weakness_Lab.html」単一ファイル版は別途提供しています。端末によってローカルファイルの保存に制限があるのでJSONバックアップを推奨。

【追加データの形式】
・新しい弱点：弱点リスト → 「弱点を追加」、または「まとめて追加」
・新しい問題：弱点の詳細 → 「問題を追加」
・ChatGPTの採点分析：設定 → 「採点結果の整理用プロンプト」→ JSONを貼り付け
・JSONは不正確な情報を自動的に検証するわけではありません。採点は公式解答例で確認してください。

【初期データ】
21弱点、30応用問題、12問の過去問演習履歴（予想点は独自推計・正式成績ではありません）
